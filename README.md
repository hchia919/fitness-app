# 我的運動紀錄 🏃

一個屬於你的個人運動紀錄 APP —— 純前端 PWA，不需要後端、不需要安裝任何套件，用瀏覽器打開就能用。

## 功能

- **新增運動紀錄**：日期、運動類型（跑步、健走、自行車、游泳、重訓、瑜珈⋯）、時間、距離、卡路里、強度、備註
- **紀錄列表**：依日期分組顯示，可隨時編輯或刪除
- **統計頁**：本週次數／時間／距離、連續運動天數、近 7 天運動時間長條圖、近 30 天運動類型分布
- **資料備份**：一鍵匯出／匯入 JSON
- **離線可用**：支援 PWA，加入主畫面後即使沒有網路也能開啟
- **深色模式**：自動跟隨系統設定

## 怎麼使用

### 直接打開

用瀏覽器打開 `index.html` 即可。

### 用本機伺服器（建議）

```bash
# 任選一種
python3 -m http.server 8000
npx serve .
```

然後打開 http://localhost:8000

### 安裝到手機主畫面

1. 把這個資料夾部署到任何靜態網站空間（GitHub Pages、Netlify、Vercel 都可以）
2. 用手機瀏覽器打開網址
3. 選「加入主畫面」，就會像原生 APP 一樣

## 資料儲存

所有紀錄都儲存在瀏覽器的 `localStorage`，**只存在你自己的裝置上**，不會上傳到任何伺服器。換裝置前記得先到「設定」頁匯出 JSON 備份。

## 專案結構

```
index.html            主頁面（紀錄／統計／設定三個分頁）
style.css             樣式（含深色模式）
app.js                應用邏輯（紀錄 CRUD、統計圖表、匯出入）
manifest.webmanifest  PWA 設定
sw.js                 Service Worker（離線快取）
icon.svg              APP 圖示
```
